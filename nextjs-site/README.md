# kidebouchetou.com - Site Next.js

Site professionnel de débouchage de canalisations, optimisé SEO avec Next.js 14.

## 🚀 Fonctionnalités

- **SEO Optimisé** : Metadata enrichi, Schema.org structured data, Open Graph
- **Design Responsive** : Mobile-first avec animations fluides
- **Performance** : Static export pour un chargement ultra-rapide
- **Accessibilité** : ARIA labels, sémantique HTML5
- **Conversion optimisée** : CTAs stratégiques pour inciter les appels

## 🎨 Thème de couleurs

- **Primaire** : Bleu marine `#1e3a5f` (basé sur le logo)
- **Accent** : Or/Orange `#f5a623` (basé sur le logo)

## 📦 Installation

```bash
npm install
```

## 🛠️ Développement

```bash
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000)

## 📁 Build

```bash
npm run build
```

Le site statique est généré dans le dossier `dist/`.

## 🔍 SEO Implémenté

- **Title & Meta descriptions** optimisés
- **Schema.org LocalBusiness** structured data
- **Open Graph** pour réseaux sociaux
- **Canonical URLs**
- **Keywords** ciblés (débouchage, canalisation, Sarcelles, Saint-Ouen)
- **Alt text** sur toutes les images
- **Semantic HTML5** (header, nav, main, section, footer)

## 📱 Sections du site

1. **Hero** : Logo, titre accrocheur, téléphone en évidence
2. **Services** : 6 cartes de services avec icônes
3. **À Propos** : Histoire, expertise, valeurs
4. **Pourquoi Nous** : Comparaison avec plombiers généraux
5. **Conséquences** : Problèmes liés aux bouchages
6. **Tarifs** : 3 forfaits clairement présentés
7. **Localisation** : Sarcelles & Saint-Ouen
8. **Contact** : Formulaire + infos de contact
9. **Footer** : Liens, coordonnées, copyright
